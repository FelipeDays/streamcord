NÍVEL DO ÁUDIO ENVIADO —
COMO CONFIGURAR (WINDOWS)
  1. Instale o VB-CABLE (gratuito) em vb-audio.com/Cable e reinicie o PC.
  2. Windows › Configurações › Sistema › Som › Mixer de volume: no app do vídeo/jogo, mude a saída para CABLE Input. O Discord fica no seu fone normal.
  3. Aqui, escolha CABLE Output como entrada e ative Ouvir no meu fone.
  4. Se o vídeo estiver no mesmo navegador onde roda o BAGRESTREAM, as telas dos amigos também iriam pro cabo. Use outro navegador para o vídeo (ex.: BAGRESTREAM no Firefox, vídeo no Chrome).
